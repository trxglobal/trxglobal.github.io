1. 本站的性质

TRX Global（trxglobal.github.io，以下简称“本站”）是 TRXAPI 能量租赁服务的介绍与引导页面。本站不提供账户注册、登录、充值或下单功能，这些操作均在 TRXAPI 官方站点（www.trxapi.io、login.trxapi.io）完成，并适用该站点的隐私政策与服务条款。

2. 我们收集的信息

本站不要求您填写任何个人信息，也不收集钱包私钥、助记词或密码。访问本站时，可能会产生以下数据：

  • 托管服务日志：本站托管于 GitHub Pages，GitHub 可能出于安全和运维目的记录访问者 IP 地址等信息，详见 GitHub 隐私声明。
  • 广告与转化统计：本站可能使用 Google Ads 转化跟踪（gtag.js），以统计广告点击后的注册 / 登录点击次数。Google 可能通过 Cookie 或类似技术收集设备与浏览信息。
  • 来源参数：如果您通过广告访问本站，链接中的 gclid、utm_* 等来源参数会在本次浏览会话内临时保存在浏览器中，并在您点击注册 / 登录时附加到跳转链接上，用于统计推广效果。

3. 信息的使用

以上数据仅用于衡量广告效果和改进本站内容，我们不会出售或出租任何访问者信息。

4. 第三方服务

  • GitHub Pages：GitHub 隐私声明
  • Google 广告：Google 如何使用广告信息；您可以在 Google 广告设置中关闭个性化广告。
  • TRXAPI：注册、登录及使用能量租赁服务时，请阅读 trxapi.io 上的相关条款。

5. 您的权利

您可以随时通过浏览器设置清除或禁用 Cookie 与本地存储，这不会影响您浏览本站。
