隱私政策

更新日期：2026 年 9 月 29 日

1. 本站的性質

TRX Global（trxglobal.github.io，以下簡稱“本站”）是 TRXAPI 能量租賃服務的介紹與引導頁面。本站不提供帳戶註冊、登入、儲值或下單功能，這些操作均在 TRXAPI 官方站點（www.trxapi.io、login.trxapi.io）完成，並適用該站點的隱私政策與服務條款。

2. 我們收集的資訊

本站不要求您填寫任何個人資訊，也不收集錢包私鑰、助記詞或密碼。訪問本站時，可能會產生以下資料：

  • 託管服務日誌：本站託管於 GitHub Pages，GitHub 可能出於安全和運維目的記錄訪問者 IP 地址等資訊，詳見 GitHub 隱私聲明。
  • 廣告與轉化統計：本站可能使用 Google Ads 轉化跟蹤（gtag.js），以統計廣告點擊後的註冊 / 登入點擊次數。Google 可能通過 Cookie 或類似技術收集設備與瀏覽資訊。
  • 來源參數：如果您通過廣告訪問本站，鏈接中的 gclid、utm_* 等來源參數會在本次瀏覽會話內臨時保存在瀏覽器中，並在您點擊註冊 / 登入時附加到跳轉鏈接上，用於統計推廣效果。

3. 資訊的使用

以上資料僅用於衡量廣告效果和改進本站內容，我們不會出售或出租任何訪問者資訊。

4. 第三方服務

  • GitHub Pages：GitHub 隱私聲明
  • Google 廣告：Google 如何使用廣告資訊；您可以在 Google 廣告設置中關閉個性化廣告。
  • TRXAPI：註冊、登入及使用能量租賃服務時，請閱讀 trxapi.io 上的相關條款。

5. 您的權利

您可以隨時通過瀏覽器設置清除或禁用 Cookie 與本地存儲，這不會影響您瀏覽本站。

6. 聯絡我們

如對本政策有任何疑問，請發送郵件至 admin@coinepay.cc，或通過 Telegram @coinepay_jas 聯絡客服。
